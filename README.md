# Spanish in the Present

A lightweight Spanish study site for learners who understand 30–50% of what they hear and want to close the gap fast: textbook chapters, a full verb conjugation sheet, spaced-repetition drills, and a phrase book. Latin American Spanish.

It is a static site, so it needs no build step and no server code.

## Files

| Path | What it is |
|---|---|
| `index.html` | The whole site: chapters, verb sheet, drills, phrases (HTML, CSS and JS in one file) |
| `verbs.json` | Conjugations for 128 common verbs, generated by the script below. One tense per line, so regenerating it gives a diff you can actually read |
| `tools/verbs_list.py` | The verb list and English meanings, in rough frequency order |
| `tools/build_verbs.py` | Regenerates `verbs.json` (`pip install -r requirements.txt`, then `python tools/build_verbs.py`) |
| `requirements.txt` | Pins verbecc 2.1.0 — the version that reproduces the committed `verbs.json` byte for byte |

## Run it locally

The page loads `verbs.json` with `fetch`, so open it through a local server, not by double-clicking:

```
python3 -m http.server 8000
# then open http://localhost:8000
```

## Publish with GitHub Pages

Settings → Pages → Build and deployment → Source: **Deploy from a branch** → Branch: `main`, folder `/ (root)`.
The site appears at `https://<user>.github.io/<repo>/` a minute after each push.
(Pages on a private repo needs a paid GitHub plan; on a public repo it's free.)

## Making changes

- **Chapter text:** each chapter is an `<article class="chapter" id="chN" data-title="...">` block in `index.html`. The table of contents builds itself from these.
- **Phrases:** the `PHRASES` array in the `<script>` at the bottom of `index.html`.
- **Add a verb:** add it to `tools/verbs_list.py`, rerun `tools/build_verbs.py`. Check the diff before committing — it is one tense per line, so a change shows up where it happened.
- **A verb with no usable imperative** (`haber`, `gustar`): add it to `SKIP` in `tools/build_verbs.py` and those tenses disappear from the sheet, the cards and the drills.
- **A backwards verb** (`gustar`-class, where the thing liked is the subject): add it to `DATIVE`, and only the `él/ella` and `ellos` forms get drilled.
- **Wrong conjugation:** add a correction to `PARTICIPLE_FIXES` or `COMMAND_FIXES` in `tools/build_verbs.py` (or add a new fix there), rerun, and check the verb's card on the site.

Work on a branch and open a pull request so the others can try the change before it goes live.

## Notes

- Drill progress is stored in each browser's localStorage, so it doesn't sync between devices or people yet. Use **Export** on the drill page to save a copy; **Import** merges a file back in, keeping whichever copy of an item has been practised more. Clearing site data wipes progress, and only an export survives it.
- **Audio** uses the browser's own Spanish voices — nothing is hosted and it works offline. The site prefers a Latin American voice (es-MX, es-US, es-419…) over a Spain one. If the device has no Spanish voice the audio options hide themselves. In Recognize you can also hide the text and answer from the sound alone, which is the closest thing here to real listening practice.
- Forms shown in red on the verb sheet differ from the regular -ar/-er/-ir pattern; this is computed in the page, not stored in the data.
- The site is public but carries `noindex` and a `robots.txt` that disallows crawling, so it does
  not appear in search results. It is a prototype, not a launch. Delete both to change that.
